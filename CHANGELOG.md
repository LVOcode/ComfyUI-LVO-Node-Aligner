# Changelog

## 1.0.0 — 2026-09-25

Initial standalone extraction of LVO Node Aligner from ComfyUI-LVOcode.

- Include the existing LVO alignment, exact-gap, snap, Fill and reference features.
- Include pinned and collapsed node handling, saved panel position and English help.
- Replace the full-package shared import with a local renderer helper.
- Add an independent ComfyUI frontend entry point and English documentation.
- Preserve upstream attribution, GPLv3 license text and Pixaroma MIT notice.
- Verify the extracted code with geometry and mocked-browser regression tests.
